## Funzionalità

- Crea e modifica circuiti elettrici.
- Aggiungi etichette matematiche, annotazioni elettriche ed evidenziazioni modificabili.
- Posiziona, allinea e distanzia gli elementi con precisione.
- Riutilizza blocchi predefiniti e personali.
- Copia i circuiti come immagini PNG trasparenti.
- Salva il lavoro localmente, senza account.

## Sviluppo

Richiede **Node.js 26.5.0**, indicato in [.nvmrc](.nvmrc).

```sh
git clone https://github.com/andrelombardo/DrawCircuit.git
cd DrawCircuit
npm ci
npm run dev
```
