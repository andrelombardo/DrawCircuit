# Comic Relief

Unmodified regular (400) and bold (700) WOFF2 fonts from Jeff Davis's
[Comic Relief v1.210 release](https://github.com/loudifier/Comic-Relief/releases/tag/v1.210).
The full fonts include Latin, Greek and Cyrillic glyphs.

Copyright © 2013, The Comic Relief Project Authors. Distributed under the
[SIL Open Font License 1.1](OFL.txt). This license applies to the font files,
not to DrawCircuit or documents created with it.

The app serves these fonts itself; it does not request Google Fonts or use an
installed copy. Both faces load before the editor mounts. SVG exports embed the
same files and their license, so PNG rasterization also uses Comic Relief.
`public/fonts/comic-relief/OFL.txt` preserves the license in the deployed build.
